Get started

  1. Search the Workbench or choose API Lab, Network or Data. Open the tool for your task.
  2. Enter a server address and the required port or scheme. Use an endpoint you control or are authorized to test.
  3. Tap Send, Connect or Probe. For socket tools, enter a message after connection and tap Send message.
  4. Use the bookmark button to save an endpoint. Headers, bodies and recognized credentials are not saved.

Why won't my local server connect?

Check that your device and server can reach each other, that the service is listening on the right network interface, and that the port and protocol match. On a physical iPhone, 127.0.0.1 refers to the phone, not your Mac. Use your development computer's reachable address. Check iOS Settings → Privacy & Security → Local Network and your firewall.

Why did the connection close?

WireBench ends sessions when it enters the background or you leave the tool. iOS does not allow an ordinary utility app to keep arbitrary network sessions running indefinitely in the background.

Limits and formats

HTTP responses are limited to 2 MiB; request bodies and WebSocket messages to 256 KiB. UDP payloads must contain 1–65,507 bytes; empty datagrams are not reliably supported by the system networking API. Session logs retain the newest entries up to 200 messages and a 4 MiB text budget. Data Studio accepts up to 1 MiB of input. TCP is a byte stream: receive events are chunks and are not guaranteed to match individual sends. HEX input uses pairs of hexadecimal digits; whitespace is allowed. Base64 input must be valid Base64.

Trust and interpretation

TLS uses normal system trust. Untrusted certificates are rejected. TCP Probe measures connection setup, not ICMP round-trip time. UDP readiness is not proof of delivery. JWT decoding does not verify a signature or validate claims. Redaction helps with common credentials, but always inspect shared content. TCP and encoded binary session exports omit payloads and include only metadata, because stream chunks may split a credential.

New diagnostic and import tools

ICMP Ping sends four IPv4 echo requests; filtered replies can time out even when a server is healthy. DNS Lookup uses the system resolver for IPv4/IPv6 addresses. Port Check accepts up to 16 comma-separated TCP ports on one host. TLS Inspector uses normal system trust and shows the negotiated protocol, cipher and certificate-chain subject/fingerprints. It does not display unverified certificate dates. SSE stops at 200 events, 4 MiB, 30 seconds of inactivity or five minutes total; it does not reconnect automatically. cURL imports support a documented subset, do not execute shell commands, and never send automatically.

Delete local data

Open Settings → Delete all local records. You can also delete individual saved endpoints or clear history. See the privacy policy for backups, sharing and support email handling.

快速开始

  1. 在工作台搜索工具，或筛选接口联调、网络诊断与数据工具分类。
  2. 输入服务器地址及端口或协议。仅测试你拥有或获授权的端点。
  3. 点击发送、连接或探测。Socket 工具连接后可输入消息并发送。
  4. 点击书签按钮保存端点。请求头、请求体与识别出的凭证不会保存。

为什么连不上本地服务器？

检查设备与服务器是否互通，服务是否监听正确的网络接口，端口和协议是否匹配。真机上的 127.0.0.1 指向手机自身，而非 Mac，请使用开发电脑可访问的地址。检查 iOS“设置 → 隐私与安全性 → 本地网络”以及防火墙。

为什么连接会关闭？

应用进入后台或离开工具页时，会结束会话。iOS 不允许普通工具应用在后台无限维持任意网络连接。

容量与格式

HTTP 响应上限 2 MiB，请求体和 WebSocket 单条消息上限 256 KiB。UDP 发送内容应包含 1–65,507 字节；系统网络 API 无法可靠处理空数据报。会话日志最多保留最新 200 条，并有 4 MiB 文本总量限制。数据工坊输入上限 1 MiB。TCP 是字节流，接收块不保证与每次发送一一对应。HEX 输入应为成对十六进制数字，可包含空格；Base64 输入应符合 Base64 格式。

如何理解结果？

TLS 使用系统信任校验，不可信证书会被拒绝。TCP 探测测量建连耗时，并非 ICMP 往返时间。UDP 就绪不代表已送达。JWT 解码不验证签名或声明可信性。脱敏只能帮助识别常见凭证，请务必检查分享内容。TCP 与编码后二进制会话的导出省略报文，仅保留元数据，因为流分块可能拆开一个凭证。

新增诊断与导入工具

ICMP Ping 发送 4 次 IPv4 回显请求，服务正常时也可能因过滤而超时。DNS 查询使用系统解析器返回 IPv4 / IPv6 地址。端口检测支持单主机最多 16 个以英文逗号分隔的 TCP 端口。TLS 检查使用系统信任，展示协商协议、密码套件以及证书链主体和指纹，不显示未经读取的证书日期。SSE 达到 200 条事件、4 MiB、30 秒无活动或总时长 5 分钟时停止，不自动重连。cURL 导入仅支持应用列明的语法子集，不执行 Shell 命令，也不会自动发送。

删除本地数据

进入“设置 → 删除全部本地记录”，也可单独删除收藏或清空历史。关于备份、分享与支持邮件处理，请查看隐私政策。
